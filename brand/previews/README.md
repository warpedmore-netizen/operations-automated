# Brand preview images

These images make the current draft direction viewable in conversations, decision packs and other places that cannot open the live HTML examples.

- `brand-review-board-1600x1000.png` combines the mark, signature message, shared palette, first application pilot and controlled-document direction.

The previews are generated by `brand/scripts/build-assets.mjs`. They are examples, not visual source files and not evidence of external-publication approval.
