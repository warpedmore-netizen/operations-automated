# MVP plan

## Smallest complete slice

Browse a seeded obligation chain; review a scenario observation; accept a candidate finding; create and diff a multi-object proposal; record a named human decision; release new policy/procedure versions; generate approved documents and release notes; inspect versions and audit events.

## Next increments

1. Validate usefulness and governance behaviour with non-confidential facilitated demonstrations.
2. Add server-side TypeScript domain types and Prisma/SQLite persistence.
3. Add authentication, authorisation, transactional invariants and full create/link screens.
4. Add evidence access controls and reproducible document exports.
5. Evaluate, then separately approve, any AI, Confluence or Jira connection.
