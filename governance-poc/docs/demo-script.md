# Demo script

Allow 10 minutes. State that everything is fictional and no compliance claim is made. Start on Dashboard, then show the chain in Traceability. In Scenario compare expected 15-minute notification with actual 43 minutes. In Finding point out the AI label and accept it as a human. Create Change Proposal, inspect both diffs and approve. Create Release, show `1.1`, the validation test and generated release notes. In Versions compare superseded and approved records. End on Audit log.

Ask: did the connected chain make the reason, authority and downstream impact of the wording change easier to understand? What was wrong, missing, impractical or inconsistent?
