# Jira integration

The mock adapter records intended finding-ticket creation. A real adapter may create finding and remediation issues, route reviews, link stable governance IDs and synchronise action status. Governance approval remains in the authoritative system unless a future decision explicitly delegates a Jira workflow. Define field mapping, identity, permissions, idempotency, reconciliation, deletion and failure recovery before connection.
