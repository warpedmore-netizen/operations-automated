# Governance and safeguards

The demo retains original fictional source text separately from interpretation. AI output is labelled and audited and cannot directly mutate a controlled record. A named non-AI human must accept the finding and decide the proposal. Release rejects an unapproved proposal. Release supersedes rather than overwrites approved versions. Generated policy and procedure views select approved revisions only.

These are application invariants, not production assurance. Browser identity can be impersonated, audit data can be edited, and local storage is unsuitable for confidential information. Production requires authentication, authorisation, transactional storage, append-only audit protection, evidence access classification enforcement, exception records with owner/reason/expiry and independent security, privacy, legal and accessibility review.
