# Method pilots

This directory retains evidence from applying OPERATE to real, non-confidential problems before a software product is defined or built.

Each pilot should contain:

- A user-defined value matrix
- An OPERATE record
- A learning review
- Clear retained lessons, decisions or improvements

Pilots are evidence, not demonstrations designed to make the methodology appear successful. They should record friction, failure, uncertainty and unsuitable options openly enough to guide the next version.
