# Authorise release consolidation and Confluence Draft

## Decision

Jamie Peppard asked Operations Automated to reconcile all retained suggestions, feedback and prior pull-request work into a workable current source; update the methodology; make the resulting draft available in GitHub and Confluence; and leave the Workbench able to support the continuing update and publication route.

## Authority granted

This authorises:

- integration of the outstanding proposal branches into one controlled repository state;
- preservation of superseded or historical evidence without presenting it as current;
- creation of the proposed consolidated methodology v0.8;
- push of the integrated source to GitHub, including the authoritative `main` branch;
- publication of the committed v0.8 reading copy beneath the existing controlled private Confluence **Draft** parent; and
- proportionate tests and receipts proving that the Workbench route remains usable.

## Authority not granted

This decision does not:

- approve v0.8 as current methodology;
- change the status of any proposed product, brand or methodology artefact to approved;
- authorise Confluence **Live** promotion;
- authorise external publication, a hosted Workbench deployment, new audiences or new permissions;
- resolve a future source conflict without review; or
- transfer Jamie's approval, risk-acceptance or publication authority to AI.

## Interpretation

“Push live” is implemented here as making the integrated repository source current on GitHub and making the proposed methodology readable in the private Confluence Draft area. It is not interpreted as approval of methodology meaning or as external deployment.

## Required evidence

The release is complete only when:

1. every retained proposal branch is an ancestor of the integrated source or has an explicit supersession disposition;
2. the repository and application checks pass;
3. the pushed GitHub commit is identifiable;
4. the Confluence plan is conflict-free and targets Draft only;
5. the publication receipt is retained; and
6. a second comparison reports the managed Draft pages unchanged.
