# 10 — Tools and reference

## Purpose and intended reader

This chapter helps a reader select, understand and reuse the smallest tool that advances the work. It is for methodology users, facilitators, authors and reviewers.

Templates support reasoning, evidence and decisions; completion of a form is not evidence that the operational outcome has improved.

## Questions this chapter answers

- Which tool is proportionate to the current need?
- What should the user enter and what will the tool help them decide or produce?
- Which parts are evidence, judgement, inference, assumption or recommendation?
- What cannot be concluded from the tool?
- How does the output continue into assessment, implementation, governance or review?
- What standard should a new practice guide meet?

## Topics

- Tool selection and progressive disclosure
- Value, assessment, decision, learning and methodology-change records
- Decision aids and transparent calculation
- Worked examples and user guides
- Glossary, terminology and cross-references
- Practice-guide authoring and completeness
- Version, status and validation boundaries

## Expected inputs

- Reader route and immediate outcome
- Consequence, uncertainty, reversibility and authority
- Information to collect, compare, decide or retain
- User capability, accessibility and preferred form
- Existing record or organisational system that should remain authoritative
- Methodology version and relevant approved guidance

## Outputs

- Selected tool and reason for its use
- Plain instructions and minimum required inputs
- Completed evidence, decision, assessment or learning record
- Visible limitations and human control point
- Export, retention or continuation route
- Identified need for a new or improved guide

## Interfaces and hand-offs

| Interface | Tool consideration |
|---|---|
| Methodology chapter or practice | The tool must implement, not silently reinterpret, the current guidance |
| User and affected people | Instructions, language, accessibility and effort must be proportionate |
| Organisational system of record | Avoid duplicate or conflicting authoritative records |
| Decision-maker or approver | Show evidence, recommendation, conditions and exact authority required |
| Product or delivery surface | Retain version, provenance, editability, export and recovery |
| Methodology evolution | Feed confusion, failure and repeated unmet need into controlled feedback |

## Known gaps

- No approved tool chooser maps common questions to the smallest useful artefact.
- Most templates have not been independently tested with a new user.
- Several templates are too comprehensive for a first response and need concise variants.
- A glossary, notation standard, role index and measure library do not yet exist.
- Template-to-methodology version compatibility is not automated.
- Worked examples across different practice families are missing.
