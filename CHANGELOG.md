# Changelog

All material changes to Operations Automated will be recorded here.

## Application MVP 0.1 - private test

- Approved by Jamie Peppard for private testing on 2026-07-20.
- Added a private, local-first OPERATE workspace with no external dependencies or connections.
- Added a governed next-action engine covering all seven OPERATE stages.
- Added named human approval gates with automatic invalidation after affected evidence changes.
- Added local persistence, activity history, Markdown and JSON export, JSON import and a Codex-ready AI brief.
- Added a product definition, validation criteria and provisional recurring-revenue strategy.
- Added automated governance, export, import-contract and interface checks.

## 0.3 - Working method

- Approved by Jamie Peppard for internal piloting on 2026-07-20.
- Defined an AI-led, human-controlled repository workflow with explicit approval boundaries.
- Clarified that `main` is controlled project memory and artefact status determines governance state.
- Added a practical user-defined value-matrix template.
- Added a learning-review template that retains lessons, decisions and improvements.
- Integrated both working artefacts into the OPERATE lifecycle.
- Added a plain-language starting route for practitioners.
- Added a living roadmap from methodology foundation to a validated, private working product.

## 0.2 - Foundation proposal

- Defined user value as the basis for deciding what “better” means.
- Added a value matrix covering outcomes, beneficiaries, priorities, constraints and decision authority.
- Established learning through bounded, observable, proportionate and recoverable failure.
- Added explicit routes back to Examine or Redesign when no option is suitable.
- Replaced the employer-specific repository boundary with a generic confidentiality boundary.
- Added the proposed principles to the Founder Charter.

## 0.1 - Foundation proposal

- Established the Founder Charter.
- Defined the OPERATE lifecycle.
- Defined TIGIPI as a human-factors heuristic.
- Established initial authority and change controls.
- Added proposal and decision templates.
