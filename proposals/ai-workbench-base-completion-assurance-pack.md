## Alternatives and strongest no-change case

1. Keep the 1.7.0 mechanics and use separate specialist screens and APIs.
2. Add only documentation and a manual evidence checklist.
3. Add a new Methodology Learning canonical work record.
4. Build the broader Founder Control Room and assurance extensions now.

Alternative 1 is the strongest no-change case because the underlying controls already pass. It is rejected for this proposal because Jamie's base definition requires an understandable end-to-end operating experience, not only stored mechanics. Alternative 3 duplicates authority. Alternative 4 exceeds the explicit scope.
